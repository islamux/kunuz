# كنوز من السنة النبوية — Kunuz

[English](README.md) | [العربية](README.ar.md)

موسوعة حرة مفتوحة المصدر تضم **١٤٠ حديثاً نبوياً موثقاً** («كنوزاً») منتقاة من سلاسل وفيديوهات فضيلة الشيخ **محمود المصري (أبو عمار)** — وأهمها سلسلتا *«كنوز من السنة»* و*«كنوز وأسرار»*. كل كنز معروض بنص الحديث كاملاً، والراوي، والمصدر، ودرجة الحديث، والشرح الميسر، والتطبيق العملي اليومي.

وهذا مشروع مستقل لتيسير العمل بذلك المحتوى وفهرسته، **وليس منشوراً رسمياً** من الشيخ.

## المميزات

- **١٤٠ حديثاً موثقاً** موزعة على **٩ أبواب** (الأذكار، الصلاة، التوبة، تفريج الكروب والرقية، فضائل القرآن، الأخلاق، الصدقات، الصيام، الآداب والسنن)
- **بحث ذكي بالعربية** — يجده بالتشكيل أو بدونه، مع توحيد همزات الألف والتاء المربوطة والألف المقصورة
- **كنز اليوم** — كنز مختار بحساب ثابت يتجدد يومياً عبر الموسوعة
- **المفضلة** — حفظ الكنوز للرجوع إليها (محفوظة في `localStorage`)
- **المسبحة والعداد** — عداد ذكر تفاعلي بعدد تكرار مخصص لكل حديث، مع إمكانية الصوت والاهتزاز
- **الورد اليومي** — قائمة سنن يومية (أذكار الصباح والمساء، الوتر، الاستغفار…) مع تتبع الإنجاز وعدّ الأيام المتتالية
- **الاستماع** — سماع الحديث بالنطق العربي (Text-To-Speech)
- **المشاركة** — نسخ نص الكنز كاملاً، أو مشاركته مباشرة على واتساب وتيليجرام
- **راحة القراءة** — واجهة عربية RTL بخطي أميري وتجوال، ثلاثة أحجام للخط، وإظهار/إخفاء التشكيل

## التقنيات المستخدمة

- [React 19](https://react.dev) + [TypeScript](https://www.typescriptlang.org)
- [Vite](https://vite.dev) + [Tailwind CSS v4](https://tailwindcss.com)
- أيقونات [lucide-react](https://lucide.dev) وتأثيرات [canvas-confetti](https://github.com/catdad/canvas-confetti)
- [Vitest](https://vitest.dev) + [Testing Library](https://testing-library.com) لاختبارات الوحدات والمكوّنات

## البدء

**المتطلبات:** [Node.js](https://nodejs.org) إصدار ٢٠ أو أحدث، و[pnpm](https://pnpm.io) إصدار ١١ أو أحدث

```bash
# 1. تثبيت الحزم
pnpm install

# 2. تشغيل خادم التطوير (http://localhost:3000)
pnpm dev
```

## الأوامر

| الأمر               | الوصف                                     |
| ------------------- | ----------------------------------------- |
| `pnpm dev`          | تشغيل خادم التطوير على المنفذ 3000        |
| `pnpm build`        | بناء نسخة الإنتاج في مجلد `dist/`         |
| `pnpm preview`      | معاينة نسخة الإنتاج محلياً                |
| `pnpm lint`         | فحص الأنواع عبر `tsc --noEmit`            |
| `pnpm test`         | تشغيل الاختبارات مرة واحدة (Vitest)       |
| `pnpm test:watch`   | تشغيل الاختبارات في وضع المتابعة          |
| `pnpm clean`        | حذف `dist/` وملفات البناء المتروكة        |

## هيكل المشروع

```
src/
├── App.tsx                  # التخطيط الرئيسي: التبويبات والتصفية وربط النوافذ
├── main.tsx                 # نقطة دخول React
├── index.css                # ستايل Tailwind v4
├── components/              # الشريط العلوي، بطاقات الكنوز، تصفية الأبواب، النوافذ، الأيقونات
├── data/                    # ١٤٠ كنزاً (٤ ملفات) + بيانات الأبواب
│   └── index.ts             # الدمج، عدّادات الأبواب، اختيار اليوم/العشوائي
├── types.ts                 # أنواع TypeScript المشتركة
├── test/setup.ts            # إعداد Vitest (jsdom + محاكاة)
└── utils/                   # دوال محضة مختبَرة
    ├── arabic.ts            # تطبيع العربية والبحث
    ├── dailyTasks.ts        # مخزن الورد اليومي وحساب الأيام المتتالية
    ├── share.ts             # تنسيق رسالة المشاركة
    └── speech.ts            # النطق العربي (TTS)
```

## المصدر والنسبة

جميع نصوص الأحاديث والشروح والتطبيقات العملية منتقاة من سلاسل وفيديوهات فضيلة الشيخ **محمود المصري (أبو عمار)** حفظه الله — وأبرزها سلسلتا *«كنوز من السنة»* و*«كنوز وأسرار»* — مع التوثيق بالنص والراوي والمصدر ودرجة الحديث.
